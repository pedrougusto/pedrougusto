## 🤖 AI Agents & Generative AI

I design and build **AI agents with Claude and other LLMs** that sit on top of the data layer, not beside it:

- **Analytics agents** that query BigQuery, read dashboards and documents, and return answers and executive summaries in business language
- **Workflow automation agents** that take over repetitive analytics tasks: report generation, data checks, campaign analysis and documentation
- **Domain assistants** that combine prompt engineering, tool use / function calling and company context (metrics definitions, KPIs, playbooks) to support Marketing and Sales teams
- Focus on **reliability**: grounded answers, clear scope for each agent, and human review where decisions matter
